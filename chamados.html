Como Abrir um Chamado

Guia passo a passo para o preenchimento correto do formulário de chamados internos. Passe o mouse sobre os ícones i para ver a descrição de cada campo.

1

Acesse o sistema

Entre na plataforma de chamados com seu login corporativo.

2

Preencha o formulário

Preencha todos os campos obrigatórios marcados com * com atenção.

3

Faça a requisição

Clique em FAZER REQUISIÇÃO para registrar seu chamado.
